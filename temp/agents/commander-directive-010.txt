خروجی اصلی

یک Blueprint مرجع برای Discovery Core بساز که حداقل این وضعیت را تثبیت کند:

ARCHITECTURE_PROVEN=YES
CONTRACT_PROVEN=YES
IN_MEMORY_E2E_PROVEN=YES
PRODUCTION_READY=NO

و دقیقاً تفکیک کند:

PROVEN:
- Source Registry contracts
- Collector boundary
- Discovery Intake
- Candidate Storage contract/reference adapter
- Entity Resolution
- Discovery Pipeline
- Source Health Evaluation
- Governance Gate
- E2E in-memory workflow

NOT_PROVEN_FOR_PRODUCTION:
- PostgreSQL Discovery persistence
- Observation persistence
- Governance persistence
- concurrency
- worker runtime
- scheduler
- real credentials
- live authenticated TrustMRR ingestion
- production observability
- production secrets management
- deployment/runtime recovery
