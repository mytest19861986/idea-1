FINDING-SEC016-001

SEVERITY=HIGH
CATEGORY=SECRET_LIFETIME / MEMORY_RETENTION

REPORTED=

VALUE_AWARE_REDACTION=
Dynamic value registration in bounded FIFO Set, 500 cap

SECRET_LIFETIME_MODEL=
EPHEMERAL_PER_CALL

SECRET_VALUE_CACHE=
NO

These statements are mutually inconsistent.

A Set containing previously resolved raw secret values is a secret-value retention mechanism,
regardless of whether it is called:

redaction registry
FIFO
cache
known-value set

A 500-entry bound limits memory growth.

It does NOT make secret storage ephemeral.

SECURITY IMPACT

A long-lived redaction registry can retain:

rotated credentials

credentials from previous executions

credentials from unrelated sources

credentials longer than their authorized execution scope

It also increases the amount of raw secret material resident in process memory.

This directly conflicts with:

SEC-I018 — EPHEMERAL LIFETIME
SEC-I019 — SECRET_VALUE_CACHE=NO

REQUIRED ARCHITECTURE

Raw secret values must not be registered into a process-global,
module-global, singleton, or other cross-execution redaction store.

Preferred model:

Secret resolution
↓
Per-execution SecretRedactionScope
↓
Collector execution
↓
Sanitize result/error/telemetry before boundary crossing
↓
dispose/clear execution scope in finally

Allowed implementation patterns include:

A)

redactSensitive(value, {
knownSecretValues: [currentExecutionSecret]
})

with no persistent registration.

or:

B)

const scope = createSecretRedactionScope()

scope.register(secret)

try {
...
} finally {
scope.clear()
}

provided the scope is strictly per execution and cannot leak across concurrent tasks.

FORBIDDEN

globalKnownSecrets.add(secret)

moduleLevelSecretSet

singleton secret history

cross-task FIFO of raw secret values

process-lifetime rotated-secret retention

IMPORTANT

Do NOT claim cryptographic memory zeroization.

JavaScript strings cannot provide that guarantee.

Correct claim remains:

SECRET_LIFETIME_MINIMIZED=YES

SECRET_MEMORY_ZEROIZED=NO_CLAIM
